# Art

Three paintings of riders and their horses, each with the Sarjy mark placed on the saddle: the name's story (Sarj is saddle, Sarjy is "my saddle") told in pictures. Made by Turki as brand material. How they are used is still open (covers, the presentation, a page backdrop).
